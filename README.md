---

## 📖 Описание

Path Finder — это Windows Forms приложение на C#, которое позволяет:
-  **Рисовать запретные области** мышью на карте
- 🎯 **Задавать целевую точку** через перетаскивание или ввод координат
- 📐 **Визуализировать** ортогональную и радиальную сетки
- 💾 **Сохранять** карту в виде массивов данных (54×44 для ортогональной, 52×36 для радиальной)
- 🔍 **Отображать препятствия** в виде цветных маркеров
-  **Запускать алгоритмы** поиска пути (в разработке)

## 📋 Описание основных файлов

### 🎨 Path_finder_win.cs
**Основной файл формы** (~400 строк)
- Обработчики событий мыши (рисование, перемещение точки)
- Управление CheckBox и ComboBox
- Синхронизация TextBox с координатами
- Кнопки "Сохранить" и "Очистить"

**Где добавлять:**
- Новые обработчики кнопок
- Дополнительную UI логику

### 🗺️ MapBuilder.cs
**Построитель карт** (~150 строк)
- `Build_ortogonal_map()` — создает массив 54×44 (0=препятствие, 1=свободно)
- `Build_radial_map()` — создает массив 52×36 в полярных координатах
- Анализирует пиксели изображения, определяет красные зоны

**Где добавлять:**
- Новые алгоритмы анализа изображений
- Поддержку других типов карт

### 🎨 GridRenderer.cs
**Рендерер сеток** (~200 строк)
- `DrawOrthogonal()` — рисует ортогональную сетку
- `DrawRadial()` — рисует радиальную сетку (полуокружности + лучи)
- `DrawObstacleCirclesOrthogonal()` — красные кружки препятствий
- `DrawObstacleCirclesRadial()` — синие кружки препятствий
- `RenderGridsToBitmap()` — полная перерисовка фона

**Где добавлять:**
- Новые типы сеток (гексагональная, изометрическая)
- Дополнительные стили отображения

### ✅ AimCounter.cs
**Валидатор координат** (~80 строк)
- `ValidateTextBox()` — проверка на число и диапазон
- `ApplyTextBoxValue()` — применение значения с откатом при ошибке
- `UpdateTextBoxStyle()` — красная подсветка ошибок

**Где добавлять:**
- Дополнительные правила валидации
- Форматирование вывода

### 📖 Использование
1. Рисование запретных зон
Зажмите левую кнопку мыши на синем поле
Ведите мышь для рисования красных линий
Линии полупрозрачные (видно сетку под ними)
2. Сохранение карты
Нажмите "Сохранить" (внизу)
Чекбоксы активизируются
Появится статус "Карта сохранена"
3. Визуализация
☑ "Отобразить ортогональную сетку" — серая сетка 15×15
☑ "Отобразить радиальную сетку" — синие дуги и лучи
☑ "Ортогональная карта" — красные кружки в ячейках-препятствиях
☑ "Радиальная карта" — синие кружки в секторах-препятствиях
4. Целевая точка
Перетащите зеленый квадрат мышью
Или введите координаты в поля X и Y
Нажмите Enter для применения
При ошибке ввода поле подсветится красным
5. Построение маршрута
Выберите тип карты в выпадающем списке
Нажмите "Старт"
(Функция в разработке)
6. Очистка
Нажмите "Очистить"
Все сотрется, чекбоксы отключатся

### 📊 Структура данных
## Ортогональная карта
Размер: 54 колонки × 44 строки
Ячейка: 15×15 пикселей
Значения: 0 = препятствие, 1 = свободно
## Радиальная карта
Размер: 52 кольца × 36 секторов
Кольцо: радиус кратен 15 пикселям
Сектор: угол 5° (180°-360°)
Центр: (400, 660) — середина нижней границы
Значения: 0 = препятствие, 1 = свободно
### Известные проблемы
Волновой алгоритм не реализован (заглушка на 300 сек)
При изменении размера окна сетка не масштабируется
Нет сохранения/загрузки карт в файл
